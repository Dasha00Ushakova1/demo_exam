Финальная проверка

Что мы вообще делаем?

Прежде чем писать код, давай поймем, как устроено приложение. Это как ресторан:

1. База данных (SQLite) — это Кладовая

Там лежат продукты (товары). У каждой коробки есть название, цена и количество. База данных хранится в файле database.db.

2. Entity Framework (EF) — это Официант

Ты (программист) не ходишь в кладовую сам. Ты говоришь официанту (EF): «Принеси все товары». Официант берет список (модели C#) и приносит данные.

3. XAML — это Витрина

Это то, как выглядит приложение. Кнопки, картинки, список. XAML — это язык разметки (как HTML), где мы рисуем интерфейс.

4. C# — это Мозг

Этот код оживляет кнопки. Когда ты нажимаешь «Добавить», C# говорит базе: «Запиши новый товар».

Модуль 1: База данных

Задача: Превратить Excel-таблицы в рабочую базу данных.

⚠️ Внимание! Программа DB Browser не понимает формат Excel (.xlsx). Нам нужно превратить их в текст (.csv).

Шаг 1: Конвертация

1. Открой файл Products.xlsx в Excel.

2. Нажми Файл -> Сохранить как.

3. В поле «Тип файла» выбери CSV UTF-8 (разделитель — запятая). Почему UTF-8? Чтобы русские буквы не превратились в иероглифы.

4. Сохрани. Повтори для всех таблиц (Users, Orders и т.д.).

Шаг 2: Импорт

1. Открой DB Browser. Нажми New Database и сохрани как database.db.

2. Меню Файл -> Импорт -> Таблица из CSV-файла.

3. Выбери файл Products.csv. Имя таблицы: products.

САМОЕ ГЛАВНОЕ: Внизу окна импорта посмотри на колонку «Тип». По умолчанию везде стоит TEXT (текст).

Найди колонку Price (Цена) и поменяй тип на REAL (дробное число). Найди Quantity (Количество) и ID — поменяй на INTEGER (целое число). Если этого не сделать, программа не сможет считать скидки и выведет ошибку.

4. Нажми ОК. Таблица создастся и заполнится.

5. В конце нажми кнопку «Записать изменения» (Write Changes) в верхней панели.

Модуль 2: Создание WPF (Интерфейс)

Задача: Нарисовать окно программы и вывести список товаров.

Шаг 1: Создание проекта

1. Открой Visual Studio -> Создать проект.

2. Найди в поиске Приложение WPF (.NET). (Не бери .NET Framework, он устарел).

3. Назови проект, например, ChudoObuv.

Шаг 2: Установка пакетов

Чтобы C# понимал базу данных, нужно скачать библиотеки.

1. Нажми ПКМ по проекту в Обозревателе решений -> Управление пакетами NuGet.

2. Установи два пакета: Microsoft.EntityFrameworkCore.Sqlite и Microsoft.EntityFrameworkCore.Proxies.

Шаг 3: Файлы в проект

Перетащи файл database.db и папку Images в проект (в Обозреватель решений).

⚠️ Критически важно: Выдели database.db, внизу в Свойствах выбери «Копировать в выходной каталог: Копировать всегда». Выдели все картинки в папке Images, в Свойствах выбери «Действие при сборке: Ресурс».

Шаг 4: Генерация моделей (Магия)

Вместо того чтобы писать классы вручную, мы сгенерируем их за 5 секунд.

1. В меню: Вид -> Другие окна -> Консоль диспетчера пакетов.

2. Внизу вставь эту команду и нажми Enter:

Scaffold-DbContext "Data Source=database.db" Microsoft.EntityFrameworkCore.Sqlite -OutputDir Models -Force

Появится папка Models с готовыми классами ваших таблиц.

Шаг 5: Включаем загрузку связей

В папке Models открой файл Context.cs (или файл с именем вашей БД). Найди строку UseSqlite и добавь под ней:

optionsBuilder.UseLazyLoadingProxies();

В моделях (например, Product.cs) перед навигационными свойствами (Category, Manufacturer) добавь слово virtual. Пример: public virtual Category Category { get; set; }

Шаг 6: Верстка (XAML)

Открой MainWindow.xaml. Удали всё внутри <Grid> и вставь этот код. Это наша витрина:

<ListView x:Name="ProductList" Margin="10">
    <ListView.ItemTemplate>
        <DataTemplate>
            <Grid Width="800" Height="150" Margin="5">
                <Rectangle Fill="LightGray" Stroke="Black"/>
                <Image Source="{Binding ImgPath}" Width="100" Height="100" Margin="10,0,0,0" HorizontalAlignment="Left"/>
                <StackPanel Margin="120,10,0,0">
                    <TextBlock Text="{Binding ProdName}" FontSize="16" FontWeight="Bold"/>
                    <TextBlock Text="{Binding CatName}" FontSize="14" Margin="0,5"/>
                    <TextBlock Text="{Binding Cost, StringFormat={}{0} руб.}" FontSize="18" FontWeight="Bold" Margin="0,10,0,0"/>
                    <TextBlock Text="{Binding Qty, StringFormat=На складе: {0} шт.}" FontSize="12"/>
                </StackPanel>
            </Grid>
        </DataTemplate>
    </ListView.ItemTemplate>
</ListView>
Как это читать? {Binding ProdName} означает: «Эй, C#! Найди переменную ProdName и покажи её здесь». ListView сам создаст такие карточки для каждого товара.

Шаг 7: Код логики (C#)

Открой MainWindow.xaml.cs. Замени весь код на этот. Не забудь поменять ChudoObuv на имя своего проекта!

using System.Windows;
using ChudoObuv.Models; // ИМЯ ТВОЕГО ПРОЕКТА
using System.Linq;

namespace ChudoObuv
{
    public partial class MainWindow : Window
    {
        // db - это наш "официант", через него мы общаемся с базой
        private Context db = new Context(); 

        public MainWindow()
        {
            InitializeComponent();
            LoadData(); // Запускаем загрузку при старте
        }

        private void LoadData()
        {
            // Идем в базу, берем все товары и формируем из них список
            var products = db.Products.Select(p => new {
                ProdName = p.ProductName, // Название
                CatName = p.Category.Name, // Категория (через связь)
                Cost = p.Price, // Цена
                Qty = p.StockItems.Sum(s => s.Quantity), // Считаем общий остаток
                ImgPath = string.IsNullOrEmpty(p.ImagePath) 
                            ? "/Images/picture.png" // Если нет картинки - заглушка
                            : "/Images/Products/" + p.ImagePath // Иначе путь к файлу
            }).ToList();

            ProductList.ItemsSource = products; // Отдаем данные на витрину (ListView)
        }
    }
}

Модуль 3: Кнопки (Добавление и Удаление)

Задача: Научить программу удалять и добавлять товары в базу.

Шаг 1: Кнопки в XAML

В MainWindow.xaml перед <ListView> добавь панель с кнопками:

<StackPanel Orientation="Horizontal" Margin="10" VerticalAlignment="Top">
    <Button x:Name="AddBtn" Content="Добавить" Click="AddBtn_Click" Width="100" Margin="0,0,5,0"/>
    <Button x:Name="DelBtn" Content="Удалить" Click="DelBtn_Click" Width="100"/>
</StackPanel>

Шаг 2: Удаление (Код C#)

В MainWindow.xaml.cs добавь метод:

private void DelBtn_Click(object sender, RoutedEventArgs e)
{
    // 1. Узнаем, какой товар выделил пользователь
    dynamic selected = ProductList.SelectedItem;
    if (selected == null) {
        MessageBox.Show("Сначала выберите товар!");
        return;
    }

    // 2. Ищем этот товар в базе по ID
    var productToDelete = db.Products.FirstOrDefault(p => p.Id == selected.Id);

    // 3. Если нашли — удаляем и сохраняем
    if (productToDelete != null)
    {
        db.Products.Remove(productToDelete);
        db.SaveChanges(); // ВАЖНО! Сохраняем изменения в базе
        LoadData();       // Обновляем список на экране
    }
}
Зачем SaveChanges()? Если ты удалишь товар из программы, но не вызовешь этот метод, база данных не узнает об этом и при перезапуске товар вернется.

Шаг 3: Добавление (Новое окно)

1. Нажми ПКМ по проекту -> Добавить -> Окно (WPF). Назови AddWindow.xaml.

2. Внутри <Grid> вставь:

<StackPanel Margin="20">
    <TextBlock Text="Название:"/>
    <TextBox x:Name="NameBox" Margin="0,0,0,10"/>
    <TextBlock Text="Цена:"/>
    <TextBox x:Name="PriceBox" Margin="0,0,0,20"/>
    <Button Content="Сохранить" Click="SaveBtn_Click"/>
</StackPanel>

3. В AddWindow.xaml.cs пишем логику:

private void SaveBtn_Click(object sender, RoutedEventArgs e)
{
    using (var db = new Context()) 
    {
        // Создаем новый товар и берем данные из текстовых полей
        var newProduct = new Product();
        newProduct.ProductName = NameBox.Text; 
        newProduct.Price = decimal.Parse(PriceBox.Text); // Переводим текст в число

        db.Products.Add(newProduct);
        db.SaveChanges(); // Сохраняем
    }
    this.Close(); // Закрываем окно
}

4. В главном окне, на кнопку "Добавить":

private void AddBtn_Click(object sender, RoutedEventArgs e)
{
    new AddWindow().ShowDialog(); // Показываем окно
    LoadData(); // Обновляем список
}

Модуль 4: Роли (Скрытие кнопок)

Задача: Скрыть кнопки удаления и добавления для Менеджера.

Visible vs Collapsed: У кнопок есть свойство Visibility (Видимость). Если поставить Collapsed — кнопка полностью исчезнет, а список сдвинется. Если поставить Hidden — кнопка исчезнет, но оставит пустое место.

В MainWindow.xaml.cs, в метод LoadData() в самом начале добавь этот код:

// Имитация проверки роли (в реальности брать из БД)
string userRole = "Менеджер"; 

if (userRole == "Менеджер")
{
    AddBtn.Visibility = Visibility.Collapsed;
    DelBtn.Visibility = Visibility.Collapsed;
}
else 
{
    AddBtn.Visibility = Visibility.Visible;
    DelBtn.Visibility = Visibility.Visible;
}
