Что мы вообще делаем?

Разработка приложения — это как постройка дома. Есть 4 главных кирпичика:

1. База данных (SQLite) — это склад

Представь склад с коробками. В коробках лежат данные: названия товаров, цены, имена клиентов. Мы не можем просто так залезть в коробку, нам нужен кладовщик.

2. Язык C# — это мозг

Он говорит кладовщику: «Эй, принеси мне все товары!». Но C# не умеет напрямую разговаривать с базой данных.

3. Entity Framework (EF) — это переводчик

Он стоит между C# и Базой Данных. Ты пишешь команду на C#, а EF переводит её на язык SQL, понятный базе.

4. WPF и XAML — это витрина

То, что видит пользователь (окошки, кнопки). XAML — это разметка (как HTML), а C# — это логика.

Модуль 1: База данных

Задача: Превратить Excel-файлы в базу данных SQLite.

⚠️ Почему нельзя просто открыть .xlsx? Программа DB Browser понимает только текстовые форматы. Поэтому Excel нужно пересохранить.

Шаг 1: Готовим файлы

Открой каждый файл Excel. Нажми Файл -> Сохранить как. В типе файла выбери CSV UTF-8 (разделитель — запятая). Почему UTF-8? Чтобы русские буквы не превратились в иероглифы.

Шаг 2: Импортируем

  1. Открой DB Browser. Нажми "New Database" и сохрани как database.db.
  2. Меню Файл -> Импорт -> Таблица из CSV. Выбери свой файл.
  3. Кодировка — UTF-8. Галочка "Первая строка содержит имена" — ОБЯЗАТЕЛЬНО.
  4. ВНИМАНИЕ: Внизу окна посмотри на типы. Если Цена (Price) стала TEXT, поменяй на REAL. ID и Количество — на INTEGER. Почему? Потому что с текстом нельзя делать математику (считать скидки).
  5. Нажми ОК. База создана!

В конце нажми кнопку "Записать изменения" (Write Changes) в верхней панели.

Модуль 2: Создание WPF

Шаг 1: Создание проекта

В Visual Studio создай Приложение WPF (.NET). Назови ChudoObuv.

Что такое NuGet? Это магазин библиотек. Мы скачаем два пакета: Sqlite (чтобы понимать базу) и Proxies (чтобы автоматически подгружать категории).

Шаг 2: Перетаскиваем файлы

Перетащи database.db и папку Images в проект.

⚠️ В свойствах базы поставь "Копировать всегда", а в свойствах картинок — "Ресурс". Если этого не сделать, программа при запуске не найдет файлы и вылетит.

Шаг 3: Автогенерация кода (Магия)

В меню Вид -> Другие окна -> Консоль диспетчера пакетов. Вставь:

Scaffold-DbContext "Data Source=database.db" Microsoft.EntityFrameworkCore.Sqlite -OutputDir Models -Force

Появится папка Models с готовыми классами. Это сэкономит тебе час времени!

Шаг 4: Код вывода (MainWindow.xaml.cs)

Замени ChudoObuv на имя своего проекта:

using System.Windows;
using ChudoObuv.Models; 
using System.Linq;

namespace ChudoObuv
{
    public partial class MainWindow : Window
    {
        private Context db = new Context(); 

        public MainWindow()
        {
            InitializeComponent();
            LoadData(); 
        }

        private void LoadData()
        {
            var products = db.Products.Select(p => new {
                Name = p.ProductName,
                Price = p.Price,
                Cat = p.Category.Name, 
                Img = string.IsNullOrEmpty(p.ImagePath) ? "/Images/picture.png" : "/Images/Products/" + p.ImagePath
            }).ToList();

            ProductList.ItemsSource = products; 
        }
    }
}

Модуль 3: Удаление и Добавление

Как удалить товар?

private void DeleteButton_Click(object sender, RoutedEventArgs e)
{
    dynamic selected = ProductList.SelectedItem;
    if (selected == null) {
        MessageBox.Show("Выберите товар!");
        return;
    }

    var itemToDelete = db.Products.FirstOrDefault(p => p.Id == selected.Id);
    if (itemToDelete != null)
    {
        db.Products.Remove(itemToDelete);
        db.SaveChanges(); // СОХРАНЯЕМ!
        LoadData();       
    }
}
Зачем SaveChanges()? Если ты удалил объект из списка, но не вызвал этот метод, база данных не узнает об этом. Это как написать текст в Word и закрыть без сохранения.

Как добавить товар?

Создай окно AddWindow и добавь кнопку сохранения:

private void SaveButton_Click(object sender, RoutedEventArgs e)
{
    using (var db = new Context()) 
    {
        var newProduct = new Product();
        newProduct.ProductName = NameBox.Text; 
        newProduct.Price = decimal.Parse(PriceBox.Text); 

        db.Products.Add(newProduct);
        db.SaveChanges(); 
    }
    this.Close(); 
}

Модуль 4: Роли

Задача: Скрыть кнопки, если зашел не Администратор, а Менеджер.

Visible vs Collapsed: У кнопок есть свойство Видимости. Если поставить Collapsed — кнопка исчезнет и место освободится. Если Hidden — останется пустое белое пятно. 
string role = "Менеджер"; // Проверка из БД

if (role == "Менеджер")
{
    AddButton.Visibility = Visibility.Collapsed;
    DeleteButton.Visibility = Visibility.Collapsed;
}
else 
{
    AddButton.Visibility = Visibility.Visible;
    DeleteButton.Visibility = Visibility.Visible;
}
