Модуль 1: База данных

Задача: Импортировать Excel-таблицы в SQLite без написания SQL-кода.

Шаг 1: Подготовка CSV

DB Browser не открывает .xlsx. Открой каждый файл в Excel и сделай Файл -> Сохранить как -> CSV UTF-8 (разделитель запятая).

Шаг 2: Импорт в DB Browser

  1. Открой DB Browser, создай новый файл database.db.
  2. Нажми Файл -> Импорт -> Таблица из CSV-файла.
  3. Выбери свой CSV. Задай имя таблицы (например, products).
  4. Кодировка: UTF-8. Поставь галочку «Первая строка содержит имена столбцов».
  5. ВНИМАНИЕ НА ТИПЫ: Найди колонку с ценой (Price) и смени тип с TEXT на REAL. Колонки с ID и количеством (Quantity) — на INTEGER.
  6. Нажми ОК. Таблица создастся сама!

Повтори для всех файлов, затем нажми «Записать изменения» (Write Changes).

Модуль 2: Создание проекта и вывод данных

Шаг 1: Подготовка

Создай проект Приложение WPF (.NET). Установи в NuGet пакеты: Microsoft.EntityFrameworkCore.Sqlite и Microsoft.EntityFrameworkCore.Proxies.

Перетащи в проект файл database.db и папку с картинками Images. В свойствах базы выбери «Копировать всегда», а в свойствах картинок — «Ресурс».

Шаг 2: Автогенерация моделей (Самый важный лайфхак!)

В меню Visual Studio открой: Вид -> Другие окна -> Консоль диспетчера пакетов. Вставь команду и нажми Enter:

Scaffold-DbContext "Data Source=database.db" Microsoft.EntityFrameworkCore.Sqlite -OutputDir Models -Force

Шаг 3: Включаем «Ленивую загрузку»

В папке Models открой файл контекста. Под UseSqlite(...) добавь:

optionsBuilder.UseLazyLoadingProxies();

В моделях (например, Product.cs) перед свойствами категорий добавь слово virtual.

Шаг 4: Код вывода списка (MainWindow.xaml.cs)

Этот код берет товары из БД и выводит их на экран. (Замени YourProjectName на имя твоего проекта):

using System.Windows;
using YourProjectName.Models; 
using System.Linq;

namespace YourProjectName
{
    public partial class MainWindow : Window
    {
        private Context db = new Context(); 

        public MainWindow()
        {
            InitializeComponent();
            LoadData(); 
        }

        private void LoadData()
        {
            var products = db.Products.Select(p => new {
                ProductName = p.Name,
                CategoryName = p.Category.Name, 
                Price = p.Price,
                Quantity = p.StockItems.Sum(s => s.Quantity), 
                ImagePath = string.IsNullOrEmpty(p.ImageFileName) 
                            ? "/Images/picture.png" 
                            : "/Images/Products/" + p.ImageFileName
            }).ToList();

            ProductList.ItemsSource = products;
        }
    }
}

В XAML (MainWindow.xaml) добавь <ListView x:Name="ProductList"> с шаблоном для карточек (он есть в печатной методичке).

Модуль 3: Добавление, Редактирование, Удаление

Шаг 1: Удаление

Добавь кнопку «Удалить» в XAML. В её обработчике напиши:

private void DeleteButton_Click(object sender, RoutedEventArgs e)
{
    dynamic selected = ProductList.SelectedItem;
    if (selected == null) return;

    var productToDelete = db.Products.FirstOrDefault(p => p.Id == selected.Id);
    if (productToDelete != null)
    {
        db.Products.Remove(productToDelete);
        db.SaveChanges(); 
        LoadData();       
    }
}

Шаг 2: Добавление (Окно AddWindow)

Создай новое окно WPF, назови AddWindow. Добавь текстовые поля для ввода.

Код кнопки «Сохранить» в окне AddWindow:

private void SaveButton_Click(object sender, RoutedEventArgs e)
{
    using (var db = new Context()) 
    {
        var newProduct = new Product();
        newProduct.Name = NameBox.Text; 
        newProduct.Price = float.Parse(PriceBox.Text); 

        db.Products.Add(newProduct);
        db.SaveChanges();
    }
    this.Close(); 
}

В главном окне, на кнопку «Добавить» напиши:

new AddWindow().ShowDialog(); 
LoadData();

Модуль 4: Роли (Скрытие кнопок)

Задача: Сделать так, чтобы Менеджер не мог удалять товары.

В методе, где ты загружаешь главное окно (или проверяешь логин), добавь условие:

string userRole = "Менеджер"; // Здесь должна быть проверка из БД

if (userRole == "Менеджер")
{
    // Полностью скрываем кнопки добавления и удаления
    AddButton.Visibility = Visibility.Collapsed;
    DeleteButton.Visibility = Visibility.Collapsed;
}
else if (userRole == "Администратор")
{
    AddButton.Visibility = Visibility.Visible;
    DeleteButton.Visibility = Visibility.Visible;
}

Важно: Используй Visibility.Collapsed, а не Hidden. Collapsed полностью убирает кнопку и освобождает место, а Hidden оставляет пустое пятно.
