Мини-теория: Что мы вообще делаем?

Представь, что ты строишь дом. В разработке приложения тоже есть свои "кирпичи".

1. База данных (SQLite) — это склад

Представь огромный склад с коробками. В коробках лежат данные: названия товаров, их цены, имена клиентов. Мы не можем просто так залезть в коробку, нам нужен кладовщик.

2. Язык C# — это мозг

Он говорит кладовщику: «Эй, принеси мне все товары, у которых цена меньше 1000 рублей». Но C# не умеет напрямую разговаривать с базой данных.

3. Entity Framework (EF) — это переводчик

Он стоит между C# и Базой Данных. Ты пишешь команду на C#, а EF переводит её на язык SQL, понятный базе.

4. WPF и XAML — это витрина

Это то, что видит пользователь (окошки, кнопки, картинки). XAML — это язык разметки (как HTML). Ты рисуешь кнопку в XAML, а C# говорит ей, что делать при нажатии.

Модуль 1: База данных

Задача: Превратить Excel-файлы в настоящую базу данных SQLite.

⚠️ Внимание! DB Browser (программа для баз данных) НЕ открывает файлы .xlsx. Их нужно пересохранить!

Шаг 1: Готовим файлы

Открой каждый файл Excel (например, Products.xlsx). Нажми Файл -> Сохранить как. В типе файла выбери CSV UTF-8 (разделитель — запятая). Сохрани.

Шаг 2: Импортируем

  1. Открой DB Browser for SQLite. Нажми "New Database" и сохрани файл как database.db.
  2. В меню выбери Файл -> Импорт -> Таблица из CSV-файла.
  3. Выбери свой CSV. Впиши имя таблицы (например, products).
  4. Кодировка — UTF-8. Галочка "Первая строка содержит имена" — ОБЯЗАТЕЛЬНО.
  5. САМОЕ ВАЖНОЕ: Внизу окна посмотри на типы данных. Если видишь, что Цена (Price) стала TEXT, поменяй на REAL. А ID и Количество (Quantity) на INTEGER.
  6. Нажми ОК. База создана!

После импорта всех таблиц нажми кнопку "Записать изменения" (Write Changes) в верхней панели.

Модуль 2: Создание приложения (WPF)

Задача: Создать окно программы и вывести туда товары из базы.

Шаг 1: Создание проекта

Открой Visual Studio -> Создать проект -> Найди Приложение WPF (.NET). (Не бери .NET Framework, это старая версия!). Назови проект, например, ChudoObuv.

Шаг 2: Установка пакетов

В правой панели "Обозреватель решений" нажми правой кнопкой по проекту -> Управление пакетами NuGet. Установи два пакета:

  • Microsoft.EntityFrameworkCore.Sqlite
  • Microsoft.EntityFrameworkCore.Proxies

Перетащи файл database.db и папку Images прямо в проект. Выдели базу, в свойствах внизу поставь "Копировать всегда". Выдели картинки, поставь "Ресурс".

Шаг 3: МАГИЯ! Автогенерация кода

Вместо того, чтобы писать код для каждой таблицы вручную, мы сгенерируем его за 5 секунд. В меню Visual Studio выбери Вид -> Другие окна -> Консоль диспетчера пакетов. Внизу откроется строка. Вставь туда:

Scaffold-DbContext "Data Source=database.db" Microsoft.EntityFrameworkCore.Sqlite -OutputDir Models -Force

Нажми Enter. Появится папка Models с готовыми классами!

Шаг 4: Код вывода списка

Открой MainWindow.xaml.cs и вставь этот код (замени ChudoObuv на имя своего проекта):

using System.Windows;
using ChudoObuv.Models; // Имя твоего проекта!
using System.Linq;

namespace ChudoObuv
{
    public partial class MainWindow : Window
    {
        private Context db = new Context(); 

        public MainWindow()
        {
            InitializeComponent();
            LoadData(); 
        }

        private void LoadData()
        {
            var products = db.Products.Select(p => new {
                Name = p.ProductName,
                Price = p.Price,
                Cat = p.Category.Name, 
                Img = string.IsNullOrEmpty(p.ImagePath) ? "/Images/picture.png" : "/Images/Products/" + p.ImagePath
            }).ToList();

            ProductList.ItemsSource = products; // ProductList - имя твоего ListView в XAML
        }
    }
}

Модуль 3: Управление (Добавление и Удаление)

Задача: Научить программу удалять и добавлять товары в базу данных.

Как удалить товар?

Добавь на страницу кнопку "Удалить". Дважды кликни по ней, и вставь этот код:

private void DeleteButton_Click(object sender, RoutedEventArgs e)
{
    dynamic selected = ProductList.SelectedItem;
    if (selected == null) {
        MessageBox.Show("Выберите товар!");
        return;
    }

    var itemToDelete = db.Products.FirstOrDefault(p => p.Id == selected.Id);
    if (itemToDelete != null)
    {
        db.Products.Remove(itemToDelete);
        db.SaveChanges(); // Сохраняем в БД
        LoadData();       // Обновляем список
    }
}

Как добавить товар?

Создай новое окно (Добавить -> Окно WPF), назови его AddWindow. Добавь туда TextBox для названия и цены, и кнопку "Сохранить".

private void SaveButton_Click(object sender, RoutedEventArgs e)
{
    using (var db = new Context()) 
    {
        var newProduct = new Product();
        newProduct.ProductName = NameBox.Text; // Имя TextBox для названия
        newProduct.Price = decimal.Parse(PriceBox.Text); // Имя TextBox для цены

        db.Products.Add(newProduct);
        db.SaveChanges(); // Сохраняем!
    }
    this.Close(); // Закрываем окно
}

А в главном окне, на кнопку "Добавить" напиши:

new AddWindow().ShowDialog();
LoadData(); // Обновляем список после добавления

Модуль 4: Роли и права доступа

Задача: Скрыть кнопки, если зашел не Администратор, а Менеджер.

В WPF у каждой кнопки есть свойство Visibility (Видимость).

  • Visible — кнопка видна.
  • Collapsed — кнопка исчезает, и место на экране освобождается.
  • Hidden — кнопка исчезает, но пустое место остается (плохой вариант).

Вставь этот код в конструктор главного окна (после проверки логина):

string role = "Менеджер"; // Здесь должна быть твоя проверка роли из БД

if (role == "Менеджер")
{
    AddButton.Visibility = Visibility.Collapsed;
    DeleteButton.Visibility = Visibility.Collapsed;
}
else // Администратор
{
    AddButton.Visibility = Visibility.Visible;
    DeleteButton.Visibility = Visibility.Visible;
}
