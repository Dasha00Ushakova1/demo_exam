Что мы вообще делаем?

Прежде чем писать код, давай поймем, как устроено приложение. Это как ресторан:

1. База данных (SQLite) — это Кладовая

Там лежат продукты (товары). У каждой коробки есть название, цена и количество. База данных хранится в файле database.db.

2. Entity Framework (EF) — это Официант

Ты (программист) не ходишь в кладовую сам. Ты говоришь официанту (EF): «Принеси все товары». Официант берет список (модели C#) и приносит данные.

3. XAML — это Витрина

Это то, как выглядит приложение. Кнопки, картинки, список. XAML — это язык разметки (как HTML), где мы рисуем интерфейс.

4. C# — это Мозг

Этот код оживляет кнопки. Когда ты нажимаешь «Добавить», C# говорит базе: «Запиши новый товар».

Модуль 1: База данных и Ключи

Задача: Создать таблицы, настроить связи и импортировать данные.

Шаг 1: Конвертация Excel в CSV

DB Browser не понимает .xlsx. Открой файлы в Excel и сохрани как CSV UTF-8 (разделитель запятая).

Шаг 2: Импорт таблиц

  1. Открой DB Browser, создай базу database.db.
  2. Файл -> Импорт -> Таблица из CSV. Выбери файл.
  3. КРИТИЧНО: Внизу окна смени типы данных. Цена (Price) = REAL, Количество (Quantity) = INTEGER.
  4. Нажми ОК и сохрани изменения.

Шаг 3: Настройка Первичных и Внешних ключей (Связи)

Зачем это нужно? Ключи нужны, чтобы база не удалила категорию, если на неё ссылается товар, и чтобы в заказ нельзя было добавить несуществующий размер обуви.
  1. Перейди во вкладку Database Structure (Структура БД).
  2. Нажми ПКМ по таблице (например, products) -> Изменить таблицу.
  3. Первичный ключ (PK): Дважды кликни по колонке id и поставь галочку PK (Primary Key).
  4. Внешний ключ (FK): Перейди на вкладку Foreign Keys внизу. Нажми Add.
    В колонке Table выбери таблицу-справочник (например, categories).
    В колонке To выбери id.
    В колонке From выбери category_id.
  5. Нажми ОК и Записать изменения.

Шаг 4: Составной ключ (Для склада и заказов)

В таблице stock_items товар может иметь несколько размеров. Чтобы строка была уникальной, ключ делается из двух столбцов.

  1. Открой таблицу на изменение.
  2. Выдели сразу два столбца (например, product_id и size_id), зажав Ctrl.
  3. Внизу нажми кнопку с иконкой ключа Set Primary Key.

Шаг 5: ER-диаграмма (draw.io)

1. В DB Browser: Файл -> Экспорт -> База данных в SQL. Сними галочки с INSERT.

2. Открой сайт draw.io. Меню: Упорядочить -> Вставить -> Расширенные -> SQL. Вставь код. Таблицы появятся сами!

3. Соедини их стрелками "вороньи лапки" (Один-ко-многим).

Модуль 2: Создание WPF (Всё включено)

Задача: Нарисовать интерфейс, подключить БД, вывести картинки, сделать скидки и подсветку.

Шаг 1: Подготовка проекта

Создай Приложение WPF (.NET). Установи NuGet-пакеты: Microsoft.EntityFrameworkCore.Sqlite и Microsoft.EntityFrameworkCore.Proxies.

Перетащи database.db и папку Images в проект. В свойствах базы выбери "Копировать всегда", в свойствах картинок — "Ресурс".

Шаг 2: Автогенерация моделей (Scaffold)

В консоли диспетчера пакетов (Вид -> Другие окна) выполни:

Scaffold-DbContext "Data Source=database.db" Microsoft.EntityFrameworkCore.Sqlite -OutputDir Models -Force

В Context.cs добавь optionsBuilder.UseLazyLoadingProxies();. В моделях добавь слово virtual для связей.

Шаг 3: Верстка (XAML)

Открой MainWindow.xaml. Мы добавим подсветку фона (красный, если товара мало) и вывод скидки.

<ListView x:Name="ProductList" Margin="10">
    <ListView.ItemTemplate>
        <DataTemplate>
            <Grid Width="800" Height="150" Margin="5">
                <!-- Привязка цвета фона к нашей переменной BgColor -->
                <Rectangle Fill="{Binding BgColor}" Stroke="Black" StrokeThickness="1"/>
                
                <!-- Загрузка картинки -->
                <Image Source="{Binding ImgPath}" Width="100" Height="100" Margin="10,0,0,0" HorizontalAlignment="Left"/>
                
                <StackPanel Margin="120,10,0,0">
                    <TextBlock Text="{Binding ProdName}" FontSize="16" FontWeight="Bold"/>
                    <TextBlock Text="{Binding CatName}" FontSize="14" Margin="0,5"/>
                    
                    <!-- Цена в рублях и со скидкой -->
                    <TextBlock Text="{Binding Cost, StringFormat={}{0:N2} руб.}" FontSize="18" FontWeight="Bold" Margin="0,10,0,0"/>
                    <TextBlock Text="{Binding Discount}" FontSize="14" Foreground="Red" FontWeight="Bold"/>
                    
                    <TextBlock Text="{Binding Qty, StringFormat=На складе: {0} шт.}" FontSize="12"/>
                </StackPanel>
            </Grid>
        </DataTemplate>
    </ListView.ItemTemplate>
</ListView>

Шаг 4: Код подключения и логики (C#)

Открой MainWindow.xaml.cs. Замени весь код на этот. Поменяй ChudoObuv на имя своего проекта!

using System.Windows;
using ChudoObuv.Models; // ИМЯ ТВОЕГО ПРОЕКТА
using System.Linq;

namespace ChudoObuv
{
    public partial class MainWindow : Window
    {
        // Подключение к базе данных
        private Context db = new Context(); 

        public MainWindow()
        {
            InitializeComponent();
            LoadData(); 
        }

        private void LoadData()
        {
            // Идем в базу и формируем список с расчетами
            var products = db.Products.Select(p => new {
                ProdName = p.ProductName,
                CatName = p.Category.Name,
                
                // Цена в рублях
                Cost = p.Price,
                
                // Считаем общий остаток на складе
                Qty = p.StockItems.Sum(s => s.Quantity),
                
                // Логика скидки (если товара мало - скидка 15%)
                Discount = p.StockItems.Sum(s => s.Quantity) <= 3 ? "Скидка 15%!" : "",
                
                // Логика цвета (если <= 3, то красный, иначе серый)
                BgColor = p.StockItems.Sum(s => s.Quantity) <= 3 ? "LightCoral" : "LightGray",
                
                // Путь к картинке
                ImgPath = string.IsNullOrEmpty(p.ImagePath) 
                            ? "/Images/picture.png" 
                            : "/Images/Products/" + p.ImagePath
            }).ToList();

            // Передаем список на витрину
            ProductList.ItemsSource = products; 
        }
    }
}
Разбор кода:
Cost = p.Price — берет цену из БД.
StringFormat={}{0:N2} руб. — в XAML делает так, чтобы выводилось "1000,00 руб."
BgColor — если товара мало, делает фон карточки красным.

Модуль 3: Кнопки (Добавление и Удаление)

Задача: Научить программу удалять и добавлять товары в базу.

Шаг 1: Кнопки в XAML

<StackPanel Orientation="Horizontal" Margin="10" VerticalAlignment="Top">
    <Button x:Name="AddBtn" Content="Добавить" Click="AddBtn_Click" Width="100" Margin="0,0,5,0"/>
    <Button x:Name="DelBtn" Content="Удалить" Click="DelBtn_Click" Width="100"/>
</StackPanel>

Шаг 2: Удаление (Код C#)

private void DelBtn_Click(object sender, RoutedEventArgs e)
{
    dynamic selected = ProductList.SelectedItem;
    if (selected == null) return;

    var productToDelete = db.Products.FirstOrDefault(p => p.Id == selected.Id);
    if (productToDelete != null)
    {
        db.Products.Remove(productToDelete);
        db.SaveChanges(); // ВАЖНО! Сохраняем изменения
        LoadData();       
    }
}

Шаг 3: Добавление (Новое окно)

Создай окно AddWindow.xaml. Внутри Grid:

<StackPanel Margin="20">
    <TextBlock Text="Название:"/>
    <TextBox x:Name="NameBox" Margin="0,0,0,10"/>
    <TextBlock Text="Цена:"/>
    <TextBox x:Name="PriceBox" Margin="0,0,0,20"/>
    <Button Content="Сохранить" Click="SaveBtn_Click"/>
</StackPanel>

В AddWindow.xaml.cs:

private void SaveBtn_Click(object sender, RoutedEventArgs e)
{
    using (var db = new Context()) 
    {
        var newProduct = new Product();
        newProduct.ProductName = NameBox.Text; 
        newProduct.Price = decimal.Parse(PriceBox.Text); 

        db.Products.Add(newProduct);
        db.SaveChanges(); 
    }
    this.Close(); 
}

В главном окне на кнопку "Добавить":

new AddWindow().ShowDialog();
LoadData();

Модуль 4: Роли

Задача: Скрыть кнопки для Менеджера.

string role = "Менеджер"; // Проверка из БД

if (role == "Менеджер")
{
    AddBtn.Visibility = Visibility.Collapsed;
    DelBtn.Visibility = Visibility.Collapsed;
}
else 
{
    AddBtn.Visibility = Visibility.Visible;
    DelBtn.Visibility = Visibility.Visible;
}
Используй Collapsed, чтобы кнопка исчезла и не оставила пустое место. Hidden оставит пятно.
